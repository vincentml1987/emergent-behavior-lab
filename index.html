Ten worlds start out running independently in lockstep (shared generation count, shared rules above). "Random" rolls a fresh independent pattern into every universe. Whenever a universe's grids all die out, it drops out of the lineup (its panels hide). Once only four are left standing, the run auto-pauses and "breeds" every pairwise combination of those four survivors (six pairs) — XOR of each parent's ORIGINAL starting pattern (frozen the moment it was born, never its current evolved state) — back into the empty slots, refilling the lineup to ten so you can Run again. If two or more die in the very same tick and that drops the count below four, the longest-lived of that tick's casualties are pulled back in (by their own original pattern) to round the parent pool out to four. Click or drag extra cells into any active board's center third to perturb it. A tick that would spill past an edge creates a new grid there (seeded from the overflowing edge-third, if it meets the minimum reproduction size — otherwise those cells warp to the opposite edge instead). Grid lifespan and stall window (trend-line slope near zero) remove a grid after that many generations, whichever comes first.
